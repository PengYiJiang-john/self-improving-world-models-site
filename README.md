# Self-Improving World Models — Website

这是研究网站的公开发布文件，介绍基于模型的控制、Self / World / Others，以及贯穿其中的递归自我改进（RSI）。

This repository contains the public website files for a research proposal on model-based control, Self / World / Others, and recursive self-improvement (RSI).

网页支持中文和英文；所有运行时资源均已本地打包，无需安装依赖或构建。将仓库根目录发布到 GitHub Pages 即可。真实静态子页 `body.html`、`platonic.html` 和 `rsi.html` 使用相对链接，支持 GitHub Pages 项目子路径。

The bilingual site includes all runtime assets and needs no install or build step. Publish the repository root with GitHub Pages. The static subpages `body.html`, `platonic.html`, and `rsi.html` use relative links and support a GitHub Pages project path.
